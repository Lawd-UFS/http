O que acontece entre o Enter e a página aparecer?

Umas cinco etapas, em menos de meio segundo. Aqui elas acontecem só quando você manda.

https://

esperando você digitar

  1. 01

    Você digita o endereço

    Para você, lawd.ufs.br é um nome. Para o computador, não significa nada ainda — ele só sabe conversar com números.

  2. 02

    O DNS traduz o nome

    O navegador pergunta a um servidor de DNS qual é o endereço IP por trás desse nome. É a agenda de contatos da internet.

  3. 03

    O navegador faz o pedido

    Com o IP na mão, ele envia uma requisição HTTP: um bilhete de texto pedindo o arquivo principal do site.

  4. 04

    O servidor responde

    Do outro lado, o servidor procura ou monta o que foi pedido e devolve uma resposta HTTP: um código de status mais o conteúdo.

    200 é o que acabou de acontecer: achei o que você pediu, aqui está.

  5. 05

    O navegador monta a página

    O HTML chegou, mas ele é só o esqueleto. Ao ler o arquivo, o navegador descobre que faltam outras coisas — e pede cada uma com uma nova requisição.
